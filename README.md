# System24 TUI Portfolio

A personal portfolio built with a terminal/TUI aesthetic (System24 theme). Built with Vite, Vanilla HTML, CSS, and JavaScript.

## Features

- **TUI Design:** Minimalist layout resembling a terminal UI with Catppuccin-inspired neon colors.
- **Dynamic Uptime/Age Tracker:** Calculates the exact age in years, months, and days dynamically.
- **Multilingual Support (i18n):** Translates between PT-BR and EN-US instantly without page reload.
- **Interactive:** Draggable windows (coming soon), custom CSS blink animations.
- **Easter Egg:** A tiny Neko cat that follows your cursor around the screen.

## Development

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/hugotakeda/Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Built With

- **[Vite](https://vitejs.dev/)** - Frontend tooling
- **HTML5 & CSS3** - No external heavy frameworks for maximum performance
- **Vanilla JavaScript** - Core logic for interactions and translation
